# Before you run it (2 minutes)

This code was written without a Swift compiler, so it has NOT been built. Build once and send me any red errors.

1. Drag the whole folder into your Xcode project. For every NEW file, tick your app target in the File Inspector (Target Membership):
   GameUI.swift, FruitererScreen.swift, PrivacyInfo.xcprivacy
   (and make sure the GIFs, shop.gif etc. are ticked too).
2. Destination: an iPhone simulator (iOS 17 or newer).
3. Delete from the project any old file I replaced if Xcode shows duplicates (ButtonLook/GameButton now live in GameUI.swift only).
4. Product > Clean Build Folder, then Run.
5. Old saves: a 4x4 garden is moved to the middle of the new 12x12 garden automatically.

Quick test list: onboarding > Home > open garden > plant > Fruiterer (Buy / Sell) > Quests & Trophies (full screen) > finish a study session for an achievement.
